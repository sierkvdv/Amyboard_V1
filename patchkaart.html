R3MIDI — de BeatStep-lijn (leeft!)

Elke noot die je speelt — pads, SEQ1, SEQ2 — vuurt de vangst direct af op die toonhoogte, aanslaggevoelig, óók in pauze (solo-modus). De beats volgen bovendien jouw melodie. Nu via een geleend koptelefoonsnoer; eigen stereo-minijack staat op de bestellijst.
uit · vrijLater: de Weermachine stuurt zélf MIDI (bijv. terug naar de BeatStep of andere synths).

R4CV 1 — klok in, weer uit

in · tempo-volgerBeatStep CLOCK OUT → hier (mono-kabeltje). Analoge tel-pulsjes; de machine leest ze en volgt jouw tempoknop. Scherm toont dan CLK + BPM. Geen pulsjes (2,5 s) → terug naar eigen 120.
uit · weer-golfTrage golfspanning die meegolft met de storm: harde muziek = wildere golf. Bedoeld voor een filter-CV-ingang (straks je Behringer 2600) — je muziek stuurt dan het filter van je modular.

R5CV 2 — reserve in, gates uit

in · vrijExtra modulatie-ingang of meetlus. Leest −10 V tot ~+5,6 V (op USB-voeding).
uit · gates5V-blokpuls op elke kwartnoot, in het gevolgde tempo. Recht in de gate-ingang van je Behringer (drempel 4 V — ruim gehaald) of elke andere trigger-ingang.

De knop // klik = menu, draai = waarde

Eén knop, vijf werelden. Elke klik stapt door het menu; draaien zet de waarde (2 klikjes = 1 stap). Bij elke klik of draai verschijnt een grote menu-box op het scherm — naam, waarde en vijf stipjes zodat je ziet wáár je zit — plus een positiebalk (spookzone gemarkeerd, < links = doordraaien is opnieuw opnemen) en een icoon: het STORM-zonnetje draait en dooft naarmate je opendraait (achteruit in de spookzone), TONEN = huppelende nootjes, ECHO = wegstervende blokjes, GALM = uitdijende ringen, ADEM = een ademend vierkant.

Storm 0–12

01–45–8 ⇄9–12
  • 0 = machinelaag stil (*-) — alleen wash + jouw spel.
  • 1–4 = korte tikjes (±⅛ s) die in de galm uitsterven; patroon ververst elke 4 maten.
  • 5–8 = de spookzone: langere flarden, ~1 op 3 achterstevoren; verversen elke 2 maten.
  • 9–12 = chaos: het sample klinkt vol uit, octaafsprongen, vlaag-noten, elke maat een nieuw patroon.

Tonen 0–10

  • Laat de beats per maat van toonhoogte zwerven.
  • 0 = strak bij je melodie · 10 = wilde sprongen tot een octaaf.
  • Start op 3.

Echo 0–10

  • De tempo-tik die alles nagalmt.
  • 0 = helemaal droog — eindelijk.
  • Start op 5.

Galm 0–10

  • De grote ruimte (reverb).
  • 0 = droog, 10 = kathedraal in de regen.
  • Start op 8.

Adem 0–10

  • Hoe diep én snel het filter op de wash ademt.
  • 0 = stilstaand filter, 10 = diepe, snelle golven.
  • Start op 4.

Vanzelf, zonder knoppen

  • Eerste geluid na stilte → vangt automatisch (vooruit én achteruit-kopie tegelijk).
  • Beat-patroon hussalt zichzelf — hoe verder de STORM-knop, hoe vaker (4/2/1 maten).
  • Elke slag krijgt micro-drift (±15 cent) — nooit twee keer exact hetzelfde.
  • Muziek stoppen → beats spelen door (de vangst leeft in het board).
  • Board aan = alles start vanzelf; computer niet nodig, elke USB-lader werkt.

Nu aangesloten

  • PC groene uitgang → R2 line in (mono-kabeltje)
  • Koptelefoon/mixer → R2 line uit
  • BeatStep MIDI OUT → R3 MIDI in (geleend koptelefoonsnoer)
  • BeatStep CLOCK OUT → R4 CV1 in (mono-kabeltje)
  • USB-C → desktop of lader (stroom + bedieningslijn)

Noodgrepen & veiligheid

  • RST kort drukken = herstart (alles komt vanzelf terug).
  • Vastloper? RST kort, dán meteen BOOT ~5 s vasthouden = programma overslaan. (BOOT vasthouden tijdens ínpluggen = verkeerde noodstand.)
  • DIP-schakelaars achterop: alle 4 UIT = lijnniveau (nu). Alle 4 AAN = modular 10 Vpp — nooit de uitgang op AAN met een koptelefoon erin. 1&2 = ingang, 3&4 = uitgang.
  • CV-poorten kunnen ±10 V hebben; line-poorten niet.

Volgende upgrades

  • Eigen stereo-minijackkabel → koptelefoonsnoer krijgt zijn leven terug.
  • Verhuizing woonkamer: Eurorack-stroom, CV1-uit → filter Behringer, CV2-uit → gate Behringer.
  • Drone-laag (Juno-pads in de toonsoort), scenes op de BeatStep-pads.
